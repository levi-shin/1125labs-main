### 02. Booki — 독서 통장

**개발 중**

책을 읽고 기록하는 과정을 하나씩 쌓아가는 독서 기록 서비스입니다.

단순히 읽은 책의 목록을 저장하는 것이 아니라,  
내가 어떤 책을 읽어왔고 무엇을 쌓아가고 있는지를 볼 수 있도록 만들고 있습니다.

책 한 권을 읽을 때마다 독서 통장에 기록이 쌓이는 것처럼  
읽은 시간과 책에 대한 기록이 차곡차곡 남는 서비스를 만들고 있습니다.

🚧 **현재 개발 중입니다.**

### 03. 돌무화과 레이어

**가칭 · 개발 중**

성경을 읽고 탐구하기 위한 앱입니다.

본문을 읽는 것에서 끝나지 않고,  
성경 속 인물과 사건, 배경과 맥락 등을 여러 층(Layer)으로 살펴볼 수 있는 형태를 생각하고 있습니다.

아직 이름과 형태를 계속 만들어가는 중입니다.

🚧 **현재 개발 중입니다.**
